# Система учета компьютерных устройств (ООП)

Консольное приложение для учета компьютерного оборудования, построенное на принципах объектно-ориентированного программирования (ООП).

## Основные сущности (Классы)
- **Category** — категория компьютерной техники (название, ID);
- **User** — сотрудник организации (ID, имя, email);
- **State** — состояние оборудования (ID, название, доступность к выдаче);
- **Device** — экземпляр устройства, связывающий категорию, состояние и ответственного пользователя.

## Возможности
- просмотр списка устройств с детализацией связей;
- добавление новой техники с валидацией инвентарного номера (`@staticmethod`);
- проверка доступности через свойства (`@property`) и методы объекта;
- выдача устройства пользователю и оформление возврата;
- загрузка и сохранение объектной модели в формате JSON.

## Структура проекта
```text
models/        — пакет классов предметной области (Category, State, User, Device)
