# Система учета компьютерных устройств

Консольное приложение для инвентаризации компьютерной техники и учета ее выдачи сотрудникам.

## Возможности
- просмотр списка устройств;
- поиск устройства по названию;
- добавление нового оборудования;
- проверка доступности и необходимости техобслуживания;
- выдача устройства сотруднику;
- отмена выдачи (возврат оборудования);
- сортировка устройств по году закупки.

## Структура проекта
- main.py — точка запуска и главное меню;
- devices.py — функции работы с устройствами;
- assignments.py — функции выдачи и возврата техники;
- storage.py — сохранение и загрузка данных (JSON);
- utils.py — вспомогательные функции ввода;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты pytest.

## Требования
- Python 3.10+;
- pytest;
- flake8.

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
```bash
python main.py
```

## Запуск тестов
```bash
pytest
```
