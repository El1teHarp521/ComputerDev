# Система учета компьютерных устройств

## Назначение
Программа для учета компьютеров и оргтехники в организации.

## Целевая аудитория
Системные администраторы.

## Предметная область
Учет компьютерного оборудования.

## Основные сущности
- Устройство
- Сотрудник
- Кабинет

## Основные функции
- Проверка доступности устройства к выдаче
- Расчет срока службы оборудования
- Проверка необходимости техобслуживания

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
